# @tolt/api

TypeScript SDK for the Tolt API (v2). Run it on your server: it needs your secret API key. Requires Node 18 or newer.

## Install

```bash
npm install @tolt/api
```

## Usage

```ts
import { ToltApiClient } from "@tolt/api";

const tolt = new ToltApiClient({ token: process.env.TOLT_API_KEY! });

const { data: partner } = await tolt.partners.get({ id: "part_8fKq2LmZx7RtYw3nVbHc5dPj" });

for await (const customer of await tolt.customers.list()) {
  console.log(customer.id);
}
```

Single-item calls return the API envelope, so read `.data`. `list` returns a page: iterate it with `for await` to walk every page, or read `page.data` for one page.

Resources: `partners`, `customers`, `transactions`, `commissions`, `links`, `clicks`, `promotionCodes`, `programs`, `groups`, `flows`, `reports`, `embedTokens`.

## Errors

```ts
import { ToltApi, ToltApiError, ToltApiTimeoutError } from "@tolt/api";

try {
  await tolt.partners.get({ id: "part_8fKq2LmZx7RtYw3nVbHc5dPj" });
} catch (err) {
  if (err instanceof ToltApi.NotFoundError) {
    // err.body.code === "not_found"
  } else if (err instanceof ToltApiTimeoutError) {
    // no response within timeoutInSeconds
  } else if (err instanceof ToltApiError) {
    console.error(err.statusCode, err.body, err.requestId);
  }
}
```

## Retries and timeouts

Failed requests (408, 429, 5xx) are retried twice with backoff. Calls that create something (every `create`, and `transactions.rerunFlows`) are never retried, so a server error can't create a duplicate. Override per client or per call:

```ts
const tolt = new ToltApiClient({ token: process.env.TOLT_API_KEY!, maxRetries: 3, timeoutInSeconds: 30 });
```

The client talks to `https://platform.tolt.com` by default. Pass `baseUrl` to point it elsewhere.

## Development

`src/` is generated by [Fern](https://buildwithfern.com) from the API's OpenAPI spec in [toltapp/tolt-sdks](https://github.com/toltapp/tolt-sdks), which opens a pull request here when the spec changes. Don't edit `src/` by hand.

```bash
npm ci
npm run build
npm test
```
